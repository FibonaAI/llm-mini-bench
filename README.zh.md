# LLM Mini Bench

[English](README.md)

**用较少的题目和费用，快速了解一个语言模型的能力。**

换模型、换渠道或调整 Thinking 后，先跑一组小测，看看它能答对什么、是否遵守指令、能否完成工具任务，再决定是否值得继续使用和深入测试。LLM Mini Bench 支持对照模型、账号和 Thinking 设置，保留回答和估算费用，让比较不只凭感觉。

可以独立运行，也可以直接在 Magpie 中使用。

## 测什么

Mini Bench 共 **14 题**，覆盖六个方面：

| 方面 | 题目内容 |
| --- | --- |
| 知识 | 遗传密码、DNS 缓存、条约规则 |
| 推理 | 概率、因果反事实、任务调度 |
| 代码语义 | 引用与 `finally`、并发事务 |
| 材料整合 | 支付记录、双时间修订 |
| 指令遵从 | 耦合转换、引用中的指令 |
| 工具操作 | 库存约束、预订冲突恢复 |

题库刻意保持小规模，适合初筛和发现值得继续测试的问题，不代表全面能力评估或模型排行榜。工具题只操作模拟器，不会修改真实库存或日历。

## 在 Magpie 中开始

在 Magpie 的插件页面，选择以下**一种**来源安装：

| 渠道 | 来源 |
| --- | --- |
| npm | `npm:llm-mini-bench` |
| GitHub | `github:FibonaAI/llm-mini-bench` |

对应的 npm 包和 GitHub 源码发布后才能安装。Magpie 会管理运行环境。安装后打开**模型评测**，插件自动初始化本地连接并读取 Magpie 的模型目录，不需要手动设置 token 或端口。

### 跑一次初测

1. 打开**任务**，选择模型和 Thinking 设置。需要对照时，可以再选其他模型或设置。
2. 快速初测可以选 **1 轮**，跑完全部 14 题；想观察结果是否稳定，可以使用默认的 3 轮。
3. 核对自动更新的运行数、样本数与执行上限，点击**开始评测**。
4. 打开**分析**，对照得分和估算费用，点开结果检查逐题回答、指令检查和工具调用。

每个选中组合会生成独立运行。可以取消单次运行或整个任务，但已经发出的请求仍可能计费。工具题的一个样本可能需要多次请求。

默认由 Magpie 自动分配账号。需要对照指定的本机账号时，见[账号绑定](magpie/README.zh.md#显式本地账号绑定)。本机账号固定不能穿透到 Remote Magpie 后面的账号。

## 怎么看结果

图表将**全部 14 题的等权均分换算到百分制**，与**每轮估算美元费用或输入加输出 token 总量**对照。图表的“着色”默认按供应商-模型区分，也可选择模型、模型系列或评测时间着色，时间模式同样使用多色调色板。普通评测用圆点、基线用方块，最新实心、历史空心；仅悬停、聚焦或选中时，连接同一已记录批次、精确请求模型、渠道与账号内的不同可见 Thinking。内容得分、指令遵从、工具检查和执行状态都可以单独查看。

- 只有覆盖全部 14 题和所有计划轮次、得分有效且所选横轴用量已知的完整运行才会入图。
- 失败和缺失结果不补零。零费用记录在线性轴显示、对数轴隐藏。
- 对照时使用相同题库和执行设置。Thinking 的 `default` 不指定 reasoning，不等于显式的 `none`。
- 账号和模型标签表示请求的路由，不是已独立核验的上游身份。

完整且可评分的运行可以保存为基线，方便以后对照。工作区初始为空，只显示你自己的运行和保存的基线。详见[题目与评分说明](docs/ASSESSMENT_BANK.zh.md)。

## 不通过 Magpie 使用

需要 [Bun](https://bun.com/) 1.4.0 或更高版本：

```sh
git clone https://github.com/FibonaAI/llm-mini-bench.git
cd llm-mini-bench
```

先配置[上游路由和凭证](docs/BENCH_EXECUTION.zh.md#配置两条路由)，再启动本地服务：

```sh
export MAGPIE_BENCH_TOKEN="$(openssl rand -hex 32)"
bun benchmark/bench.ts serve
```

打开 `http://127.0.0.1:3481/#token=YOUR_TOKEN`，将 `YOUR_TOKEN` 替换为 `MAGPIE_BENCH_TOKEN` 的值，并妥善保管。启动服务不会发起模型请求。

独立运行的配置和命令行用法，包括计划、启动和取消任务，见[执行指南](docs/BENCH_EXECUTION.zh.md)。

## 费用与隐私

- 模型请求可能收费。新任务只设置每题完整执行的超时，默认 600 秒；不设置 token、请求数、费用、工具调用数或交互轮数上限。费用是估算值，不是账单。
- 题目和回答会经过所选上游，只使用可信渠道。
- 临时 API 错误默认最多重试 3 次；仍失败可在任务记录中手动重试，保留成功样本并更新结果。能力或执行上限导致的“未完成”不自动重试。创建任务超时后仍应先查历史，避免重复提交。
- 服务只监听本机 loopback，不要将端口暴露到公网或分享认证 token。
- 个人结果默认保存在 `~/.local/share/magpie-mini-bench/`，包含完整题目、回答和工具轨迹，分享前请检查内容。
