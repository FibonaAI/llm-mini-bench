# LLM Mini Bench

[English](README.md)

**用较少的题目和费用，快速了解一个语言模型的能力。**

顶部可一键切换 **2.0** 与 **1.0** 两套独立 12 题题库（评分机制、分析图表、基线与任务记录按版本严格隔离），横向对比不同模型、账号和 Thinking 设置，同时保留完整回答、工具轨迹与估算费用。支持在 Magpie 中作为插件使用，也可独立运行。

## 测什么

工作区默认打开 **2.0**（采用极简无引导题干、中性答案结构与证据门控交互评分，兼顾高分段区分度与低冗余耗时），也可随时切回 **1.0** 查看既有结果或继续评测：

| 维度 | 2.0 题目（共 12 题） | 1.0 题目（共 12 题） |
| --- | --- | --- |
| 知识 | IPv4 伪装位反转 ASCII 溯因还原、FIDE 国际象棋合法步与将军边界计数 | HTTP 条件缓存优先级、IEEE 754 浮点与 SQL 三值逻辑 |
| 推理 | 键位错位拼音溯因还原、英文伪装摩尔斯电码极性反相还原 | 上下文代数同态归纳、上下文守恒律与状态追踪 |
| 代码语义 | 四槽位环形检查点回滚撕裂读回、二次机会（Clock）缓存 Belady 异常 | 异步生成器 `finally` 覆盖、MVCC 保存点与可串行化快照 |
| 材料整合 | 跨时区故障回滚与同秒重试分母赔付对账、5 次读取预算冷链费率核查 | 多轨审计对账、紧预算条件文档核查 |
| 指令遵从 | 五阀联锁最短步启动规程、中英双语实物交接口径差异核查 | 多代理 DAG 调度规则、多义词上下文翻译核查 |
| 工具操作 | 保底深度约束 4 步反贪心继电器隔离、零拒绝签名委托清舱放行 | 自适应故障诊断、委托授权释放 |

题库刻意保持小规模，用于快速初筛而非综合排行榜。所有题目均通过固定工具提交答案并只作数据处理，绝不执行模型代码，也不触碰外部系统。

## 在 Magpie 中开始

在 Magpie 的插件页面，任选以下**一种**来源安装：

- **npm**：`npm:llm-mini-bench`
- **GitHub**：`github:FibonaAI/llm-mini-bench`

安装后打开**模型评测**即可使用。Magpie 会自动管理运行环境、连接本地服务并加载模型目录，无需手动配置端口或 token。

### 跑一次对照

1. 打开**任务**，选择一个或多个模型与 Thinking 设置。
2. 快速初测可选 **1 轮**（12 个样本），观察稳定性可保留默认的 **3 轮**（36 个样本）。
3. 确认样本数与超时设置，点击**开始评测**。
4. 打开**分析**，对照得分与费用、Token 或耗时，点击数据点查看逐题回答与调用详情。

随时可以取消单个运行或整个任务，也可以在任务记录中手动重试失败、超时、已中断或已取消的样本（已完成结果保留不重跑）。如需指定本机账号而非自动分配，见[账号与 Key 绑定](magpie/README.zh.md#本地多账号与多-key-绑定)。

## 怎么看结果

图表将**全部 12 题的等权均分（百分制）**与**每轮估算费用、总 Token 或耗时**对照展示。圆点表示普通运行、方块表示基线，实心为最新、空心为历史。

- **入图条件**：仅完整覆盖 12 题及全部计划轮次的运行会入图。API 失败不补零；含超时或用量不完整的记录会标注异常角标，不参与帕累托前沿。
- **可比性**：对照时请保持题库与执行设置一致。账号和模型标签仅反映请求路由，不代表已独立核验的上游身份。
- **基线**：工作区初始为空，可将完整且可评分的运行保存为基线，用于后续对照。

图表交互、判分细节、重试策略与命令行用法，见[题目与评分说明](docs/ASSESSMENT_BANK.zh.md)和[执行指南](docs/BENCH_EXECUTION.zh.md)。

## 不通过 Magpie 使用

需要 [Bun](https://bun.com/) 1.4.0 及以上版本。拉取仓库并[配置上游路由](docs/BENCH_EXECUTION.zh.md#配置两条路由)后启动服务：

```sh
git clone https://github.com/FibonaAI/llm-mini-bench.git
cd llm-mini-bench
export MAGPIE_BENCH_TOKEN="$(openssl rand -hex 32)"
bun benchmark/bench.ts serve
```

在浏览器打开 `http://127.0.0.1:3481/#token=YOUR_TOKEN`（替换为你的 `MAGPIE_BENCH_TOKEN`）。启动服务本身不会发起任何模型请求。

## 费用与隐私

- **计费与上限**：模型请求可能收费，界面费用仅为估算而非账单；新任务只设单题总超时（默认 600 秒）。
- **隐私**：题目与回答会经由所选上游发送；截图分享前可点击顶栏“账号打码”，个人记录（含完整对话与工具轨迹）默认保存在 `~/.local/share/magpie-mini-bench/`，分享前请先检查。
- **安全**：服务仅监听本机回环地址（loopback），不要暴露端口或泄露认证 token。
